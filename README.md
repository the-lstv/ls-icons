# LS.Icons v3
LS.Icons is an open-source icon library designed by Lukas, primarily for [LS](https://github.com/the-lstv/LS), but available for anyone.
This is the 3rd version after a long time and is **still work in progress**.

<img width="391" height="478" alt="Screenshot from 2026-03-29 19-54-41" src="https://cdn.extragon.cloud/file/ed9df0eae6275dc8.webp" />

## Changes compared to 2.0
- Removed outline-thin and fill-bold styles for simplicity.
- Now using a precise keyline to ensure all icons are consistent.
- Updated icon font with woff2.
- An updated style.
- Removed all legacy icons.
